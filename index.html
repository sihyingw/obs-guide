用 OBS 開台：Agora 串流設定

Go live with OBS: Agora streaming setup

跟著下面 6 個步驟，把 Moor 給你的串流金鑰接到 OBS，大約 5 分鐘可以完成。每一步都附截圖，畫面上紅框標出來的地方就是要點的按鈕或要貼上的欄位。

Follow the 6 steps below to connect your Moor stream keys to OBS — it takes about 5 minutes. Every step includes a screenshot; the red box marks the exact button to click or field to fill in.

開始之前

Before you start

  • 在電腦上下載並安裝 OBS。如果已經裝過，確認版本在 31 以上。
  • 在 swag.live 登入你的 SWAG 創作者帳號。
  • Download and install OBS on your computer. If it's already installed, make sure it's version 31 or later.
  • Log in to your SWAG creator account at swag.live.

  4. 一路點 Next，再點 Install 完成安裝。

  4. Click Next through the setup, then Install to finish.

2

開始直播，打開 Moor 的串流設定視窗

Go live and open the stream-setup window in Moor

  1. 打開 Moor（你平常直播用的網頁），點擊「開始直播」。
  2. 畫面會自動跳出一個「串流設定」視窗。
  3. 確認視窗標題寫的是 Agora RTC 串流設定。如果顯示 TRTC，點畫面最下面的「切換模式」換成 Agora。
  1. Open Moor (the web app you use to go live) and click "Start Live".
  2. A stream-setup window pops up automatically.
  3. Check the title says Agora RTC Streaming Configuration. If it shows TRTC instead, tap "Switch mode" at the bottom to switch to Agora.

Scroll down in the popup to find the "Switch mode" option.

💡 先別關掉這個視窗 — 下一步要用到裡面的 4 組資料，等全部貼到 OBS 之後才需要關。 Keep this window open — you'll copy 4 values from it in a later step. Only close it after everything is pasted into OBS.
3

在 OBS 打開聲網連麥設定

Open the Agora connect settings in OBS

  1. 開啟 OBS，點擊上方選單「工具」→「聲網連麥」。
  2. 跳出的小視窗裡，點擊「設定」。
  1. Open OBS, then click Tools → Agora RTC Tool in the top menu.
  2. In the window that appears, click Settings.
💡 Mac 上的按鈕文字有時會顯示簡體字（例如「设置」而不是「設定」），或跟截圖不完全一樣 —— 這是 Agora 插件本身翻譯不一致，位置對就是對的，不用擔心字對不上。 On Mac, some button labels may appear in Simplified Chinese or not exactly match this screenshot — that's an inconsistency in the Agora plugin's own translation, not a mistake on your end. Go by position, not exact wording.

5

開始推流

Start streaming

  1. 點擊「開始推流到聲網」。
  2. 按鈕會變成藍色的「停止推流到聲網」——這是正常的，代表已經在推流中，不是壞掉。
  3. 回到 Moor，畫面顯示「已連接訊號源」就代表成功了！
  1. Click Start Streaming to Agora.
  2. The button turns blue and changes to "Stop Streaming to Agora" — that's expected, it just means the stream is now live, not that anything broke.
  3. Back in Moor, once you see "Stream Source Connected", you're done!

常見問題

Troubleshooting

每次開播都要重新貼一次資料嗎？
是的——Channel Name 跟 Agora Token 每場直播都會變動，開播前務必回到 Moor 複製最新的值。

Do I need to re-paste the values every time?
Yes — Channel Name and Agora Token change every stream, so copy the latest values from Moor before each broadcast.

OBS 啟動時出現無法載入 "agora-ui-tools" 的錯誤？
到 C:\Program Files\obs-studio\data\obs-plugins，移除資料夾裡的 agora-tool-ui，重新安裝 Agora 插件後重啟 OBS 即可修正。 到 ~/Library/Application Support/obs-studio/plugins，移除 agora-tool-ui.plugin，重新安裝 Agora 插件後重啟 OBS 即可修正。

OBS shows an error that it can't load "agora-ui-tools"?
Go to C:\Program Files\obs-studio\data\obs-plugins, remove the agora-tool-ui folder, reinstall the Agora plugin, then restart OBS. Go to ~/Library/Application Support/obs-studio/plugins, remove agora-tool-ui.plugin, reinstall the Agora plugin, then restart OBS.
